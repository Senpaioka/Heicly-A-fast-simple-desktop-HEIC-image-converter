# Heicly

**Heicly** is a fast, offline desktop utility for Windows to convert HEIC/HEIF image files to JPG, PNG, JPEG, or WEBP formats.

## Features
- **Batch Processing**: Convert single files or entire folders at once.
- **Drag & Drop**: Easily drop your `.heic`, `.heif`, or `.hif` images.
- **Flexible Options**: Configurable output formats, quality compression, resizing, and EXIF metadata retention.
- **Theme Support**: Seamless Dark Mode & Light Mode support.
- **Privacy-First**: Works 100% offline; your photos never leave your device.
